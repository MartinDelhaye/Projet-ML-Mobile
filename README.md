# Projet-ML-Mobile

## Sujet :
Découverte du Machine Learning supervisé et des réseaux de neurones (Deep Learning) dans un contexte d’une application mobile.

## Les objectifs visés :
1. Découvrir le Machine Learning et l’apprentissage supervisé
2. Déployer un modèle d’agent appris sur un périphérique mobile en utilisant la plateforme AndroidEnv de Google DeepMind.

Tâches à réaliser :
1. Compréhension des bases du Machine Learning
2. Apprentissage des réseaux de neurones (Deep Learning)
3. Prise en main de PyTorch
4. Choix du cas d’étude
5. Développement du modèle d'agent
6. Développement de l’application Android, qui exploitera l’agent développé
7. Déploiement de l'agent

NB : Chaque étape doit être synthétisée dans un document

## Langages et technologies :
Python, PyTorch, TensorFlow, AndroidEnv, Kotlin, Android Studio
